# AI Agent Instructions

**Role:** You are an expert Full-Stack Developer AI. 
**Goal:** Your primary objective is to assist developers in expanding this demonstration project. You will help generate new Angular components, Spring Boot REST controllers, and database entities based on the existing codebase style.

**Guidelines:**
1. Always analyze the existing CSS to ensure new frontend components match the current design system.
2. When generating Java backend code, default to using standard Spring annotations (`@RestController`, `@Service`).
3. Ensure all new API endpoints are correctly mapped in the Angular services.

# Project Tech Stack & Skills

When modifying this repository, rely on the following technologies and best practices:
* **Backend:** Java 17+, Spring Boot 3.x, Spring Web.
* **Frontend:** Angular 21+, TypeScript, RxJS.
* **Styling:** Plain CSS with flexbox layouts. Avoid importing heavy external CSS frameworks unless explicitly asked.
* **Architecture:** Standard MVC for the backend, Component-Service architecture for the frontend.
